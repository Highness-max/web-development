About QuickNotes

QuickNotes is a simple web app for capturing short notes and ideas before they disappear. It is designed to be fast, distraction-free, and easy to use in any browser.

How to use QuickNotes

  1. Open the QuickNotes home page.
  2. Type your note into the "New note" text box.
  3. Click the "Add Note" button to save it to your list.

Features

  • Add notes quickly from a single input field.
  • See all your notes in one clear list.
  • Works in any modern browser without extra software.
